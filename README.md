# Lahint Permit Twin | مُطابِق

Public municipal licensing readiness prototype by Lahint.

Website: https://accma44-netizen.github.io/

The published application includes the public activity snapshot, Saudi map selection, browser-local PDF and image reading, and the solution presentation. Uploaded documents and saved drafts stay in the visitor's browser. This deployment does not issue official permits or connect to government accounts.

This repository contains only the public static distribution and dependency licenses. Private company documents, user records, credentials, and institutional runtime data are excluded.

Deploy from the main branch root with GitHub Pages. An empty .nojekyll preserves bundled static OCR assets. The source project is maintained separately; future releases replace this public distribution after integrity checks.
